# HausHoch Consult – MPE Kleebergstraße 9

Finales GitHub-Pages-Paket für die digitale Marktpreiseinschätzung.

## Dateien

- `index.html` – Hauptseite für GitHub Pages
- `index_inline.html` – optionale Einzeldatei mit eingebetteten Bildern
- `assets/` – Logo, Objektbilder, Grundrisse, Dokumentenausschnitte, Teamfotos
- `.nojekyll` – verhindert Jekyll-Filterung
- `robots.txt` – zusätzliche Noindex-/Privatsphäre-Bremse
- `site.webmanifest` – Icon-/App-Metadaten

## GitHub Pages Deployment

1. Neues Repository erstellen.
2. Inhalt dieses Ordners in den Repository-Root hochladen.
3. Unter **Settings → Pages** die Quelle `main` / `/root` auswählen.
4. Veröffentlichung abwarten und URL prüfen.

## Passwort

Die Seite enthält ein einfaches clientseitiges Passwort-Gate. Das aktuelle Passwort ist im HTML sichtbar und lautet: `haushoch`. Für wirklich vertrauliche Inhalte sollte ein privates Hosting oder ein serverseitiger Passwortschutz genutzt werden.
